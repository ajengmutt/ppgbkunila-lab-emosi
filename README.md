# LAB EMOSI — Prototipe website

## Cara mencoba
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Kuis Awal berisi 20 soal dengan teks opsi A–E dan kunci skor dari naskah sumber. Skor Bagian A dan B dijumlahkan terpisah; total maksimal 200.
4. Ruang Simulasi menerima kode kartu fisik dan menampilkan narasi lengkap dari naskah situasi.
5. Jurnal tersimpan di browser perangkat dan dapat diunduh sebagai JSON.

## Publikasi sebagai tautan
1. Buka https://app.netlify.com/drop
2. Seret folder hasil ekstrak `lab_emosi_website` ke area unggah.
3. Salin URL yang diberikan untuk dibagikan kepada siswa.

## Catatan
- Kuis merupakan bahan refleksi, bukan diagnosis. Hindari membandingkan atau mengumumkan skor siswa.
- Jurnal tidak dikirim otomatis; data tersimpan lokal di browser. Unduh salinan sebelum berganti perangkat atau membersihkan data browser.
- File `quiz-data.js` dan `situations-data.js` adalah data sumber terpisah: kuis awal dan undian situasi fisik tidak dicampur.
